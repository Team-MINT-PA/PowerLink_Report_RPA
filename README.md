# 네이버 파워링크 노출순위

키워드를 넣고 버튼을 누르면, 네이버 모바일 파워링크에서 **헤이딜러가 몇 위에 노출되는지**를
그 자리에서 세어 줍니다. 검색하고 '더보기'를 눌러 가며 손으로 세던 일을 대체합니다.

요구사항 문서: [`docs/요구사항_헤이딜러_20260816.pdf`](docs/)

---

## 1. 실행

| 운영체제 | 실행 |
|---|---|
| **윈도우** | `run_streamlit.bat` 더블클릭 |
| **macOS / 리눅스** | 터미널에서 `./run_streamlit.sh` |

둘 다 하는 일은 같습니다. 브라우저에서 <http://localhost:8501> 이 열립니다.

맥은 처음 한 번만 실행 권한을 줘야 합니다.

```bash
cd 프로젝트폴더
chmod +x run_streamlit.sh
./run_streamlit.sh
```

파이썬이 없다고 하면 `xcode-select --install` 로 애플 기본 도구를 깔거나
`brew install python` 을 쓰세요. 스크립트가 어느 쪽을 깔아야 하는지 알려 줍니다.

처음 실행하면 가상환경과 패키지를 알아서 준비합니다. 이미 되어 있으면 건너뛰므로
두 번째부터는 2초 안에 뜹니다. 무언가 꼬이면 `.venv` 폴더를 지우고 다시 실행하세요.

```
[1/2] 가상환경을 만듭니다. 처음 한 번만 걸립니다...   →  .venv 생성
[2/2] 패키지를 설치합니다...                        →  requirements.lock 으로 버전 고정
```

포트를 바꾸려면 `PORT=8600 ./run_streamlit.sh` 처럼 넘기거나,
윈도우는 `run_streamlit.bat` 의 `set PORT=8501` 을 고치세요.

수동으로 실행하려면:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock     # 윈도우는 .venv\Scripts\python
.venv/bin/python -m streamlit run streamlit_app.py
```

### 프로젝트 폴더는 짧은 경로에 두세요 (윈도우 한정)

streamlit 패키지 안에 **140자짜리 경로**가 들어 있습니다. macOS·리눅스는
경로 한계가 훨씬 커서 해당 없습니다. 프로젝트가 깊은 폴더에 있으면
설치 도중 `WinError 206 파일 이름이 너무 깁니다` 로 실패하는데, 이때 **streamlit 만 빠진 채
나머지가 깔려** 원인을 찾기 어렵습니다.

현재 위치(`C:\Users\vrsoft\Desktop\DevRosieOh\DdaengJu`, 43자) 기준 여유는 53자입니다.
`run_streamlit.bat` 이 실행 전에 경로 길이를 확인하고, 길면 설치를 시작하지 않고
무엇이 문제인지 알려 줍니다.

## 2. 쓰는 법

### 버튼을 누른 '그 시각'의 순위입니다

예약 수집이 아닙니다. 버튼을 누르는 순간 네이버에 붙어 세어 옵니다.
파워링크는 시간대마다 순위가 바뀌므로, 미리 모아 둔 값은 보고할 시점의 값이 아닙니다.

실제로 12분 사이에 이렇게 움직입니다.

| 조회 시각 | 중고차매매사이트 |
|---|---|
| 14:30 | 24위 |
| 14:42 | **25위** |

그래서 화면 맨 앞에 **조회 시각**이 뜹니다. 결과를 띄워 둔 채 30분이 지나면
"지금 순위가 아니다"라고 알리고 다시 누르라고 안내합니다.

### 결과 표

요구사항 문서와 같은 3열입니다.

| 날짜 | 키워드 | MO - 판매 |
|---|---|---|
| 2026-08-16 | 중고차매매사이트 | 25 위 |
| 2026-08-16 | 중고차가격 | 0위 |

**0위 = 미노출** 입니다(설정한 페이지 범위 안에서 못 찾음). 16위부터는 사용자가
'더보기'를 눌러야 보이는 자리입니다.

CSV·엑셀로 내려받을 수 있습니다. CSV 는 BOM 을 붙여 저장하므로 엑셀에서 한글이 깨지지 않습니다.

### 키워드

기본값은 요구사항 문서의 31개이고, 문서의 표 순서를 그대로 지킵니다.
화면에서 고칠 수 있고, 엑셀에서 셀 여러 개를 복사해 붙여넣어도 됩니다
(콤마·줄바꿈·탭 모두 구분자로 처리).

영구히 바꾸려면 `config.json` 의 `keywords` 를 고치세요.

### 사이드바 설정

| 항목 | 뜻 |
|---|---|
| 기준 업체 / 매칭어 | 광고의 **업체명·도메인**에 매칭어가 들어 있으면 우리 광고로 봅니다 |
| 반복 측정 횟수 | 파워링크는 호출마다 광고가 로테이션됩니다. 여러 번 재서 **중앙값**을 씁니다 |
| 최대 조회 페이지 | 1페이지당 15위. 10이면 150위까지 보고, 그보다 뒤면 0위로 적습니다 |
| 동시 요청 수 | 과하게 올리면 차단될 수 있습니다. 5 권장 |

**매칭어는 부분 일치라 느슨하면 남의 광고를 잡습니다.** 예전에 `다이렉트카` 하나만
두었더니 `국민다이렉트카`가 걸려 1위로 둔갑한 적이 있습니다.

## 3. 반드시 가정용 회선에서 돌리세요

**네이버는 접속한 IP에 따라 다른 광고 세트를 내려줍니다.** 데이터센터 IP로 요청하면
광고가 40%가량 적게 나오고, 그만큼 순위가 실제보다 좋게 찍힙니다.

| 키워드 | 가정용 IP | 데이터센터 IP |
|---|---|---|
| 내차팔기 | 광고 56개, 헤이딜러 **5위** | 광고 37개, 헤이딜러 **2위** |
| 중고차팔기 | 광고 73개 | 광고 44개 |

두 환경에서 각각 두 번씩 돌려 값이 완전히 같았습니다. 광고 로테이션이 아니라
IP로 갈리는 결정적 차이입니다.

**따라서 클라우드 배포(Streamlit Community Cloud, Railway, Render, GitHub Actions …)는
전부 같은 문제를 안습니다.** 잘못된 순위로 판단하느니 안 쓰는 편이 낫습니다.
어디서나 접속해야 한다면 집 PC + Cloudflare Tunnel 이 유일하게 정확한 방법입니다.

## 4. 알아 두실 점

**순위는 호출할 때마다 흔들립니다.**
입찰가 외에 광고 로테이션이 걸려 있어, 같은 조건으로 연속 호출해도 15개 중 3~4개가
다른 광고로 바뀝니다. 그래서 키워드당 기본 **3회 측정 후 중앙값**을 씁니다.

**모바일 기준입니다.**
`m.ad.search.naver.com` 의 모바일 파워링크이며 1페이지에 15개가 노출됩니다.
PC 파워링크는 페이지 구조가 달라 순위가 따로 매겨집니다.

**과도한 호출은 차단 위험이 있습니다.**
동시 요청 5개, 페이지 사이 랜덤 지연 0.25~0.7초로 제한되어 있습니다.

```
DdaengJu/

├─ run_streamlit.sh         실행 (macOS·리눅스)

├─ requirements.txt         직접 의존성 4개
├─ requirements.lock        실제 버전 조합 42개 고정
├─ docs/                    요구사항 문서
├─ data/history.jsonl       조회 이력 (추이 탭이 읽음)
└─ app/                     화면과 무관한 엔진
   ├─ collector.py          파워링크 수집·파싱·중앙값 집계
   ├─ config.py             설정 읽기/쓰기
   ├─ analytics.py          KPI·추이 집계
   └─ archive.py            이력 저장 (JSONL)
```

엔진은 화면을 모릅니다. `streamlit_app.py` 를 지워도 `app/` 은 그대로 쓸 수 있습니다.

### 순위를 어떻게 알아내는가

파워링크 목록 HTML 에 **절대 순위가 그대로** 들어 있습니다.

```
nclk(this, 'sct.title', 'nad-a001-01-000000494587285', 13)
                                                       └─ 순위
```

`&page=2`, `&page=3` … 파라미터로 16위 이후 구간을 직접 요청할 수 있어 '더보기' 클릭을
흉내 낼 필요가 없습니다. 그래서 Selenium 같은 브라우저 자동화 없이 순수 HTTP 로 동작하고,
키워드 하나가 약 1초에 끝납니다. 마크업이 바뀌어 `nclk` 가 사라지면 페이지 내 등장
순서로 순위를 계산하는 안전망이 있습니다.

### 줄바꿈은 파일 종류마다 반대입니다

- **`.bat` 는 CRLF.** LF 면 cmd.exe 가 한글이 든 줄에서 줄 경계를 잘못 잡아
  문장 조각을 명령어로 실행하려 듭니다(`'으로'은(는) 내부 또는 외부 명령...`).
- **`.sh` 는 LF.** CRLF 면 맥·리눅스 bash 가 줄 끝의 캐리지리턴까지 명령으로 읽어
  `$'<CR>': command not found` 로 죽습니다.

이 저장소는 윈도우에서 만들어 `autocrlf` 가 켜져 있으므로, 명시하지 않으면 `.sh` 가
실제로 CRLF 로 변환됩니다. `.gitattributes` 에 양쪽을 고정해 두었습니다.
